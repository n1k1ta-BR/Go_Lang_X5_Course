## Мой README файл


## Команда запуска
Запуск из корневой папки проекта
go run ./cmd/orders

## Имя настройки
Адрес задаётся переменной окружения HTTP_ADDR. Если переменная отсутствует или пустая, используется значение :8080.

## Назначения пакетов
- `cmd/orders` — точка входа: загружает настройки, создаёт хранилище, сервис и обработчик, связывает их и выводит результат.

- `internal/config` — читает HTTP_ADDR и задаёт адрес по умолчанию.

- `internal/model` — содержит структуру заказа Order.

- `internal/repository` — реализует хранение заказов в памяти, сохранение и поиск по ID.

- `internal/service` — содержит логику создания заказа, проверку имени клиента и интерфейс Repository.

- `internal/handler` — передаёт запрос на создание заказа сервису через локальный интерфейс Service.
